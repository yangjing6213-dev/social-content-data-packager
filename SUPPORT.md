# Support

## Supported scope

This project supports local packaging, validation, verification and optional transcription of
public or explicitly authorized DATATOOL exports. The repository does not promise compatibility
with every platform, account tier, browser version or DATATOOL release.

## Before asking for help

- Reproduce with synthetic or redacted inputs.
- Include the project version, Python version, operating system and command.
- Include the smallest safe error excerpt; remove credentials, cookies, signed URLs, personal data,
  media and raw comments.
- Check [README.md](README.md), [Simplified Chinese README](README.md),
  [docs/troubleshooting.md](docs/troubleshooting.md) and the existing issue templates.

## Where to ask

Use a GitHub Issue for reproducible bugs or focused feature requests:
<https://github.com/yangjing6213-dev/social-content-data-packager/issues>.
Security issues must follow [SECURITY.md](SECURITY.md), not a public issue.

This project has no unverified response-time or support-level guarantee.
