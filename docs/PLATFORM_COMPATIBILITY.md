# 平台兼容矩阵

本项目处理用户已经通过 DATATOOL 合法导出到本地的文件，不直接控制浏览器
扩展，也不承诺 DATATOOL 在任意平台、账号套餐或地区始终提供相同导出能力。

| 输入来源 | 当前状态 | 验证范围 |
|---|---|---|
| 通用标准目录 | 自动测试 | 元数据、MP4、评论 XLSX、封面和转写 JSON |
| 小红书 | 探索性人工流程 | 单条公开或授权内容；未纳入 CI 真实样本 |
| 抖音 | 待真实授权样本 | 尚未声明兼容 |
| 快手 | 待真实授权样本 | 尚未声明兼容 |
| Bilibili | 待真实授权样本 | 尚未声明兼容 |
| 其他平台 | 待验证 | 按标准输入 Schema 整理后可能可用 |

新增“已验证”状态前必须记录：平台、页面类型、DATATOOL 版本、浏览器、导出
字段、评论表头、媒体探测结果、测试日期和授权依据。不得把一次探索性成功描述
为持续、全量或官方兼容。
